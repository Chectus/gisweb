1. Общие сведения о системе

Веб-ГИС портал Лаборатории геоинформационных систем предназначен для пространственного анализа геологических данных, просмотра месторождений, тектонических структур и инфраструктуры Забайкальского края.

Совет: Для полноценной работы используйте современные браузеры (Google Chrome, Yandex Browser) с включенным аппаратным ускорением.

2. Работа с интерактивной картой

Интерфейс карты разделен на рабочую область и боковую панель управления слоями (слева).

  • Масштабирование: Используйте колесико мыши или кнопки в левом нижнем углу карты.
  • Смена подложки: В верхней части левого меню можно переключаться между векторной схемой (2GIS) и спутниковым снимком (Esri).
  • Скрытие панели: Кнопка-стрелочка сбоку от панели позволяет развернуть карту на весь экран.

3. Слои и гибридные кластеры

Все геоданные структурированы по папкам (полезные ископаемые, геология, гидрография).

Особенность точечных объектов: При отдалении карты система автоматически объединяет плотные группы точек в умные кластеры с указанием количества объектов. При приближении (зум 9 и выше) кластеры плавно заменяются на детальные векторные QML-значки из базы данных.

4. Просмотр атрибутивных таблиц

У каждого слоя в панели управления есть иконка таблицы . Нажав на неё, вы откроете правую панель со всей семантической информацией по объектам. Также доступен быстрый клик по любой точке на карте для вывода всплывающей карточки с характеристиками.

5. Управление доступом (для администраторов)

Главный геолог и администраторы системы имеют доступ к панели управления учетными записями. Через неё можно выдавать бессрочные доступы или временные логины/пароли для практикантов и сотрудников с ограничением по времени (в днях).

6. Технологический стек

Веб-портал разработан с использованием современных веб-технологий и геоинформационных платформ:

Фронтенд и UI
  • HTML5 / CSS3: Кастомизированная дизайн-система.
  • Bootstrap 5: Адаптивная сетка и компоненты интерфейса.
  • Bootstrap Icons: Профессиональная иконка графики.
  • JavaScript (ES6): Асинхронные запросы и логика карты.
Картография и ГИС
  • Leaflet.js: Клиентский картографический движок.
  • Leaflet.MarkerCluster: Динамическая кластеризация точек.
  • NextGIS Web / Server: Хранение геоданных и QML-стилей.
  • 2GIS & Esri: Базовые растровые и векторные подложки.
Бэкенд и данные

Серверная часть реализована на языке Python (Flask) с использованием шаблонизатора Jinja2 для контроля сессий и безопасности. Все пространственные слои, тектонические схемы и атрибутивные таблицы подготовлены и оцифрованы геологами лаборатории.
